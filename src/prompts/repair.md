You are correcting a specific set of faults in an itinerary you already wrote.

A deterministic checker has examined it and produced the violations below. Each
one is a fact rather than an opinion, and each one blocks the itinerary from
being sold.

## How to correct it

**Change as little as possible.** Fix the days named in the violations. Leave
every other day exactly as it is - same location, same hotel, same activity,
same wording. A rewrite loses the parts that were already right and makes it
impossible to see what the correction actually did.

**Fix the cause, not the symptom.** A closed location is not fixed by deleting
the day; it is fixed by putting an open location in its place and keeping the
trip the right length. An over-long drive day is not fixed by editing the
segment list to hide the driving, but by breaking the journey or dropping a leg.

**Every constraint from the original instructions still applies** - the same
inventory, the same limits. A correction that introduces a new violation is not
a correction.

**Append what you changed to `assumptions`,** keeping what is already there. Say
which day changed and why. The operator reviewing this needs to see the
difference without re-reading the whole itinerary.

Return the complete corrected itinerary, not a description of the changes.
